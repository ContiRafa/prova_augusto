1. O que é Virtualização? (A Analogia da Mansão)

Para entender a virtualização no primeiro semestre, pense numa Mansão Gigante (que representa um computador físico muito potente).

Historicamente, essa mansão era ocupada por uma única pessoa (o Sistema operacional tradicional). Isso gerava muito desperdício: vários quartos vazios e energia a sobrar.

A virtualização é como contratar um engenheiro para transformar essa mansão num prédio com vários apartamentos independentes. Agora, várias famílias (diferentes Sistemas Operacionais) podem morar no mesmo terreno, cada uma achando que tem a sua própria casa, com a sua própria chave, sem interferir na vida do vizinho.

Na computação, a virtualização permite que vários Sistemas Operacionais corram ao mesmo tempo num único computador físico.

2. O que é uma Máquina Virtual (VM)?

Uma Máquina Virtual (VM - Virtual Machine) é um "computador de mentira" criado por software dentro de um computador de verdade. Ela funciona exatamente como um computador físico, mas é apenas um ficheiro ou um programa a executar.

Dois termos essenciais no curso:

Host (Hospedeiro)

É o computador físico real. A máquina de verdade (ex: o portátil (notebook)).

Guest (Convidado)

É o Sistema operacional que está a correr dentro da máquina virtual (ex: um Linux a correr numa janelinha dentro do Windows).

O "Convidado" não sabe que é virtual. Ele vê o processador, memória e disco como se fossem peças físicas de verdade.

3. O Gestor do Prédio: O Hypervisor (VMM)

A resposta para evitar conflitos de recursos é o Hypervisor. Voltando à nossa analogia, ele é o Administrador do Condomínio. Ele divide a internet, a água e a luz (Processamento, Memória e Disco) de forma justa para cada apartamento (VM).

Hypervisor Tipo 1 (Nativo / Bare-Metal)

  • Como funciona: Instalado direto no hardware vazio ("na lata"). Não tem um Windows ou Linux por baixo dele.
  • Onde se usa: Grandes empresas, Data Centers (Google, Amazon). Super rápido pois não tem intermediários.
  • Exemplos: VMware ESXi, Proxmox.

Hypervisor Tipo 2 (Hospedado)

  • Como funciona:

    Instalado como uma aplicação normal dentro do seu SO (Windows, macOS, Linux).

  • Onde se usa:

    Portáteis de estudantes e programadores! (Para testar sistemas sem estragar o PC).

  • Exemplos:

    VirtualBox (muito usado na faculdade), VMware Workstation.

4. Vantagens e Desafios

Vantagens

  • Economia: 1 computador muito forte corre 10 VMs. Economiza dinheiro e espaço.
  • Segurança: Vírus na VM não afeta o Host. Basta apagar o ficheiro da VM.
  • Snapshots: O "Save game" do sistema. Permite voltar no tempo se der tela azul.

Desafios

  • Overhead: O computador faz esforço extra. A VM é sempre mais lenta que o hardware puro.
  • Ponto de falha único: Se o servidor físico queimar, todas as VMs lá dentro caem juntas.

5. Finalização

  • O que é virtualização?
    Permite criar ambientes isolados em um mesmo hardware físico.
  • Para que serve uma máquina virtual (VM)?
    Executa sistemas e aplicativos como se fosse um computador real, mas de forma virtual.
  • Função do hypervisor
    Gerencia e distribui recursos do hardware entre as VMs.
  • Diferença entre Hypervisor Tipo 1 e Tipo 2
    Tipo 1 roda direto no hardware; Tipo 2 roda sobre um sistema operacional.
  • Principais vantagens da virtualização
    Economia, flexibilidade, segurança e facilidade para testes e backups.
  • Principais desafios e limitações
    Desempenho menor que o hardware puro e dependência do servidor físico.
  • Exemplos práticos de uso
    Laboratórios virtuais, servidores de empresas, testes de software, ensino e desenvolvimento.
